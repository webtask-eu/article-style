# Общие правила (для всех стилей)

Формат строки: `- [x] ID · тип · текст`. Галочка `[x]` — правило включено, `[ ]` — выключено.
Тип `auto` проверяет скрипт `tools/rules.py audit`, тип `model` оценивает модель.
Править можно здесь (общие правила репозитория) или в `rules.local.md` (личные поправки, в git не попадают).

- [x] G1 · model · Ничего не выдумывать: цифры, имена, цитаты и кейсы только из запроса или проверенные; пробелы помечать [ФАКТ?]
- [x] G2 · auto · Не повторять подряд 8 и больше слов из образцов
- [x] G3 · model · Предложить три варианта заголовка по формулам стиля
- [x] G4 · model · Условные числа в примерах помечать как условные
- [x] G5 · model · Проверить факты: выписать проверяемые утверждения, непроверенные оставить с [ФАКТ?]
- [x] G6 · auto · Русский: без канцелярита и стоп-слов («является», «в рамках», «данный», «в целях» и т. п.)
- [x] G7 · auto · Без оборотов «не X, а Y» и «не только X, но и Y»
- [x] G8 · model · Без других «машинных» приёмов: тройки ради ритма, рубленые концовки, раздутая значимость
- [x] G9 · auto · Русский: кавычки «», тире с неразрывным пробелом, без «...» и « - »
- [x] G10 · auto · Длина предложений и абзацев в пределах допуска от целей стиля
- [x] G11 · model · В ответе есть «Что проверить автору» и «Основа»
