# Правила стиля

Формат строк как в `rules/global.md`: `- [x] ID · тип · текст`. Номера: латинская буква стиля и число, например `X1`.
После обучения впишите в строку `targets:` выше цели по длине: `words_per_sentence=13 words_per_paragraph=31 tolerance=30` (медианы из `tools/measure.py`). Для двух языков: `targets_ru:` и `targets_en:`.
