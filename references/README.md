# Как устроена папка references

Один стиль = одна папка `references/<стиль>/`:

| Файл | Что это | В git |
|---|---|---|
| `style.md` | Профиль стиля: алиасы запроса, правила, запреты | да |
| `samples/*.md` | Статьи-образцы, на которых скил учится | нет (см. ниже) |
| `learned.md` | Результат обучения: замеры и приёмы, своими словами | да |

Запрос «напиши как forbes» находит папку по `aliases` в `style.md`.

## Добавить образец
```bash
tools/add-reference.sh forbes статья.md --source https://... --title "Заголовок" --lang ru --tags кейс,стартап
pbpaste | tools/add-reference.sh fortraders - --title "Разбор рынка"
```
Новый стиль создаётся той же командой: имя папки латиницей в нижнем регистре, затем отредактируйте `aliases` в `style.md`.

## Почему образцы не уходят в публичный репозиторий
Статьи Forbes и других изданий защищены авторским правом. `.gitignore` исключает `references/*/samples/*`, образцы остаются на вашем диске. Хотите публиковать свои тексты как образцы: уберите правило из `.gitignore` для нужной папки (`tools/check.sh` тогда предупредит, что образцы отслеживаются), лицензия на эти тексты ваша забота.

## Обновить обучение
Положите новые образцы и скажите: «обнови стиль forbes». Скил перемерит образцы (`tools/measure.py`), перепишет `learned.md` и поднимет `status` до `learned`.
