# Правила стиля fortraders

Цели по длине даны отдельно для русских и английских образцов (медианы по образцам). Формат строк как в `rules/global.md`.

- [x] T1 · model · Заголовок: тема, двоеточие, вопрос читателя («почему…», «входить сразу или ждать»)
- [x] T2 · model · Вход: сцена с числами, определение, источник (регулятор или банк), затем список разделов
- [x] T3 · model · Объём около 1100 слов, абзацы по 3–5 предложений, много списков
- [x] T4 · model · Нейтральный объясняющий тон; гипотетические примеры со словом «предположим»
- [x] T5 · model · Концовка правилом, без призыва
- [x] T6 · model · Любое число о рынке, регуляторах, котировках с источником или [ФАКТ?]
- [x] T7 · model · Упомянуть риск: 0,5–1% депозита на сделку, тест на демо-счёте, право пропустить сигнал
- [x] T8 · auto · Без обещаний дохода и призывов «покупайте/продавайте»
- [x] T9 · auto · Русский: без «я», «мне», «мой» (личных историй)
